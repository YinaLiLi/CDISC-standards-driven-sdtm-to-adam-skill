# Standards Strategy

Official CDISC standards, implementation guides, controlled terminology, and study-level specifications are registered through YAML manifests in `config/standards`.

Version 1 primary support is limited to ADaM standards. SDTM and SDTMIG may be registered only as upstream reference standards for source-preserving SDTM preprocessing evaluation. They do not indicate support for Raw-to-SDTM mapping or SDTM conformance transformation.

See `docs/standards-registry.md` for the active manifest schema, registry interface, integrity checks, and process for adding new standards.
