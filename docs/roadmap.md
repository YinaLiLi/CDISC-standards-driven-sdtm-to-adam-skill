# Roadmap

Version 1 currently implements:

1. Project architecture and documentation skeleton.
2. Standards manifest registry.
3. Standards discovery.
4. Rule extraction.
5. Feasibility assessment.
6. Source-preserving preprocessing specification.
7. Approved preprocessing execution.
8. ADaM derivation specification.
9. Approved ADaM derivation execution.
10. Independent ADaM validation.
11. Evidence resolution and citation.
12. Deterministic reports.
13. End-to-end validation through the v1 pipeline facade.
14. Documentation alignment.

Developer Standards Setup utilities for standards intake, manifest finalization, SHA256 calculation, and local source identity verification are separate from the runtime workflow.

Future work must be explicitly scoped before implementation. Version 1 does not include Raw-to-SDTM mapping, SDTM conformance transformation, Define-XML generation, dashboards, statistical analysis, machine learning, AI summaries, or regulatory certification.
